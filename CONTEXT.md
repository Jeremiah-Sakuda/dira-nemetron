# Dira commitments

## Language

**Commitment**: A confirmed promise or block of work with timing, effort, ownership and authority. An unreviewed source item is a proposal, not a commitment.

**Repair plan**: A proposed sequence of typed actions that restores feasibility after a commitment changes. A valid plan still needs policy authorization before execution.

**Approved intent**: The exact desired effect authorized by the user or deterministic policy. Its absolute start and end remain fixed when the planning horizon changes; relative offsets are derived from those instants.

**Verification**: An independent external read that matches the approved intent. A successful write response alone is not verification.

**Calendar mirror**: The owner's Calendar representation of an independently booked counterparty slot. Moving this representation does not itself book that slot.

**Evidence replay**: A reproducible repair using labeled synthetic data and simulated integrations. It does not establish current provider connectivity.
